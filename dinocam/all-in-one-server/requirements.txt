# opencv-python and opencv-python-headless are BOTH installed here, pinned to the exact
# same version. This is deliberate, not an oversight: the plate SVM engine needs cv2.ml
# (present in 4.10.0.84, missing from newer opencv-python-headless releases tested), while
# uniface pulls in plain opencv-python unpinned. Installing both at a mismatched version is
# a known-bad combination (both packages ship a native cv2 extension) - pinning both to the
# identical version avoids that, verified by importing cv2.ml after a clean install of
# everything in this file together.
