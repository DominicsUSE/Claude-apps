      Google Maps API key

      The key unlocks Google ratings, review counts, phone numbers, the embedded Google listing, photos, reviews and website quality checks. It stays in this browser and is only sent to Google.

      Get a key (about 5 minutes)

      1. Open the Google Cloud console, create a project and add a billing account. Google requires one, but the free monthly allowance covers normal use of this app.
      2. Turn on three APIs: Places API (New), Maps Embed API (free) and PageSpeed Insights API (free).
      3. Go to Credentials → Create credentials → API key.
      4. Edit the key: under Website restrictions add , and under API restrictions pick the three APIs above. Paste the key here.
