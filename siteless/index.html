      Google Maps API key

      The key unlocks Google ratings, review counts, phone numbers, the embedded Google listing and website quality checks. It stays in this browser and is only sent to Google.

      Get a key (about 5 minutes)

      1. Open the Google Cloud console, create a project and add a billing account. Google requires one, but the free monthly allowance covers normal use of this app.
      2. Turn on three APIs: Places API (New), Maps Embed API (free) and PageSpeed Insights API (free).
      3. Go to Credentials → Create credentials → API key.
      4. Edit the key: under Website restrictions add , and under API restrictions pick the three APIs above. Paste the key here.

      Scanning

      Each search returns up to 20 places. Busy areas get split into smaller squares until the limit is reached.

      Google usage this month

      Google gives a free monthly allowance for each kind of request (about 1,000 for searches with ratings and websites, and for detailed listings). Website checks and the embedded map are free. See Google's pricing, and set a daily cap under Quotas in the Cloud console if you want a hard limit.
